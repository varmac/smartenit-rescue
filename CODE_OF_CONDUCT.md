# Code of Conduct

We require respectful, inclusive, and professional participation.

## Scope

This community covers all public interactions, discussions, and reviews in this
repository and associated task reports.

## Standards

Harassment, intimidation, discriminatory behavior, or abusive language is not
acceptable. We expect constructive feedback and clear technical communication.

## Enforcement

Maintainers may remove comments, pause participation, or revoke access for
behavior that violates this standard. Persistent or severe issues are escalated to
repository maintainers for enforcement.
